# 合香本机软件

本轮已实现可运行的本地首版。打开 http://127.0.0.1:8870 使用；当前只监听本机，尚未对外部署。

## 怎样进入

普通用户在界面注册账号即可。管理者使用同目录 `.local/本机管理者账号.txt` 中首次启动生成的账号；文件仅本人可读、未进入版本控制，网页接口不会返回凭据。两种角色共用香品分析，只有管理者能将自己的商品放到首页。

首页最初没有实体商品。管理者上传真实资料、选择公开字段并挂上首页后，普通用户才能看到；软件不会把设计草案伪装成在售商品。管理员也能用“我家的香”保存自己的私人咨询。

## 已有功能

- 登录注册、密码散列、会话、服务端角色与资料归属校验。
- 照片、文字、PDF、Word资料上传及本机文字提取；成分声明、香调描述、实闻与系统归类分开。
- 本人私人档案，管理者商品档案，以及公开字段、独立公开图片、商家链接和撤下。
- 材料卡点击或拖拽、三个构图角色、主调锁定、排除、中文偏好、双候选、回退和草案入口。
- 用户命名、本人设计保存、实际PNG香笺导出；状态与出处随图保存。
- 图鉴、来源与未知项、现成公开商品资料匹配。
- 独立软件模拟的方案交接、接受或拒绝、确认、开关及定时参数。

## 分析和验证范围

图片使用本机Apple Vision识别文字，文字归类与调香使用有来源的知识规则。本版没有调用外部大模型、付费接口或网页抓取，不反推秘密配方、浓度和投料比例。PDF提取前5页可读取文字；扫描PDF可改传照片。单份附件上限8MB，照片支持PNG、JPEG、WebP。

真实气味、制造、实际耗材与设备、商家成交及生产环境尚未验收。普通上传与未选公开字段不会进入首页；明确排除条件缺少产品成分依据时，匹配结果不会保证满足。

## 运行与存储

从公开仓库首次运行请先按根目录 README 建立 Python 环境并安装 requirements.txt 所声明的依赖。macOS 可双击“启动软件.command”；其他系统可执行 `python app/server.py`。原开发环境复用了已有 Pillow、pypdf 与 macOS 原生 OCR；照片 OCR 的跨系统支持尚未验证。静态界面不依赖外部字体、脚本或CDN。

账号、会话、私人资料、图片和设计保存在 `.local/`，该目录已忽略，不随源代码打包。重启不会清空资料。不要把这个目录与账号文件放到公开仓库或参赛公开包；脱敏后的证据使用 `verification/`。

## 可复核证据

- `test_app.py`：隔离临时数据，通过真实HTTP验证8组主路径与边界，包含照片OCR、越权拒绝、公开投影与图片元数据、撤下、设计保存和模拟归属。
- `qa_browser.cjs`：真实Chrome隔离资料的两种角色流程、PNG下载和390px手机布局；不修改本机正式用户资料。
- `verification/接口验收.json`、`verification/浏览器验收.json`：本轮结果；截图和导出PNG同目录。
- `知识库/验证数字调香.py`：29项调香、词汇及来源边界检查通过；知识库校验及8项反例通过。

测试数据明确为测试商品，不代表真实商家入驻、成交或用户业务验收。两份模型报告原文未改，分类与取舍入口为 `知识库/外部报告整理.md`。
