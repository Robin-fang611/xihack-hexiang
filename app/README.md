# 合香本机软件

当前实现包含自由调香、个人香笺、两类账号、私人香品分析、管理者首页推荐和软件空间模拟。14 项体验升级与五轮持续迭代已在原开发环境正式验收；本轮 GitHub 同步稿覆盖最新软件。尚未部署在线公共站点，飞书未同步本轮更新。

## 运行与进入

先按[根 README](../README.md)使用 Python 3.11+ 建立 `.venv`，安装根目录 `requirements.txt` 已声明的 Pillow 和 pypdf，然后启动服务：

```sh
.venv/bin/python app/server.py --port 8870
```

上述命令在仓库根目录运行。启动后在这台电脑打开 [127.0.0.1:8870](http://127.0.0.1:8870)，它只指向访问者自己的电脑。macOS 可双击 `启动软件.command`，优先使用仓库虚拟环境；默认仅监听本机。

普通用户在界面注册。首次初始化无管理者时自动生成本机管理者账号，凭据保存在 `.local/本机管理者账号.txt`，网页接口不返回凭据。协作者首次运行得到自己的空数据库与新账号，仓库不含默认密码或私人资料。

照片 OCR 使用 macOS Apple Vision，需要 Swift 工具链；不可用时仍可保存照片并手动补文字。文本、可提取文字的 PDF 和 Word 可用于资料分析，PDF 读取前 5 页，单份附件最多 8MB，照片支持 PNG/JPEG/WebP。完整功能目前在 macOS 验证；Linux 的照片 OCR 和 Windows 的时区/运行环境尚未全面验证。静态网页不依赖外部字体、脚本或 CDN。

## 已有功能

- 首页三个参考草案与管理者公开商品分开；无实体商品也可创作。首页图形由 AI 辅助代码绘制，不冒充实物照片。
- 材料点击、拖拽、键盘或 44px 按钮入案；主调/支撑/点缀位置、主调锁定、排除、差异候选、撤回与渐进微调。手机主操作从约 2218px 提前到约 1320px，合法单参照也可留笺。
- 本机词表将明确原话整理成待应用提案，展示原句、冲突与未知；用户应用后才影响候选。疑问、复杂否定和未收录意象保留为未知，没有调用外部模型。
- sessionStorage 留存本标签页草稿，刷新恢复输入，旧候选、核验香笺和模拟不恢复。账号/知识版本整份校验，非法原始草稿不被自动渲染覆盖；退出、401 或换号清理私人状态。
- “保存到我的香笺”和“下载 PNG”独立。前端对已知保存签名不重复发送请求，直接 API 对同账号相同规范化设计返回原记录与 HTTP 200；下载只绘制当前香笺快照，未登录或保存失败仍可执行。
- 旧作品仅查看不覆盖案头；明确“回到案头继续”后恢复为新草稿，当前排除项继续有效，原保存版本保持不变。主调锁定与接续字段参与保存比较。
- 图鉴分传统材料、现代参照、历史香方与文化规则；现代参照可按名称、资料标签和家族筛选，再选材回案头。传统同名材料与历史原名不直接进入现代混配。
- 照片、文字、PDF/Word 上传与本人资料分析，分开成分声明、品牌香调、个人实闻、系统归类和未知。管理者选择公开字段和独立去元数据图片，挂首页、修改、撤下及提供商家链接。
- 商品 revision/CAS 比较修改、发布和撤下；旧版本返回 409，保留文字、链接、价格与公开字段选择，读取最新内容对照后才保存。迟到列表 GET 保留正在修改的表单。
- 私有请求核对 X-Expected-User 与共享 Cookie 身份；重新获得焦点或可见时再查会话，跨页换号清理旧页私人内容并等待刷新。
- 软件模拟经服务端交接与确认后支持 1–120 整数分钟、开关和状态；单调时钟与后台定时器到时 auto_stop，关闭浏览器后仍计时。注销与登录替换撤销旧模拟，迟到旧交接不能重建实例。

长期保留请账号保存或下载 PNG，本标签页草稿不承担跨设备备份。计时依赖服务进程持续运行；重启后模拟需重新交接与确认。修改案头或模拟对象取消本页操作确认，不直接改写旧后台模拟，重新交接会替换该会话旧实例。

## 分析与存储边界

调香与文字归类使用本机有来源的知识规则，没有外部大模型、付费接口或网页抓取。设计主次不换算为投料比例，照片与香调描述不能反推秘密配方；资料缺失时，相近商品不能保证符合所有排除条件。数字设计尚未制作、实闻，不提供健康疗效。

账号、会话、资料、图片和设计保存在 `.local/`；新运行会自动创建，重启不清空这些业务资料。该目录与账号文件不进入公开仓库或参赛公开包。两种角色仅管理自己资料，普通上传和未选择公开的字段不会出现在首页。真实商家入驻、成交、设备、制造、生产环境与赛方验收仍未完成。

## 五轮验收与复核

原开发环境 R1–R5 均有真实源码改动和正式收据：手机路径、原话提案、草稿/作品接续、后台计时/商品冲突、图鉴/否定/锁定/身份竞态依次完成。最终同一份 38 文件运行源码指纹下，32 项基础行为与 4 项补验组成 36 项全通过；另有 57 项模块检查、9 组 HTTP、29 项调香、8 类知识边界及 12 组浏览器流程（48 项布局）。一分钟计时在独立浏览器关闭约 71.8 秒后，先看内部状态再请求 HTTP，证实后台已 auto_stop。

本次公开副本还完成了一次独立完整复验：36 项组合行为、57 项模块检查及原有完整回归全部通过；38 份运行源码与原最终版逐字节一致。公开环境的一分钟计时在独立 Chrome 关闭约 63.47 秒后已后台自动停止，先核内部状态再请求 HTTP；可配置的验证工具指纹与结果见公开摘要的 public_copy_validation。

公开摘录为[五轮验收摘要](verification/五轮公开验收.json)与[精选截图和 PNG](verification/五轮截图/)，摘要列原收据与 38 份运行源码指纹。历史原始截图、内部交接、失败尝试和完整源码/工具快照仍留原环境；公开摘录不能代替原不可变收据。R1 开始/完成和 R2 开始仅存工具指纹，后期增加工具快照，按各轮原声明审计。

当前浏览器复核在 `app/` 目录运行，使用根目录已准备的虚拟环境，以及已有 Node、Playwright、Chrome：

```sh
../.venv/bin/python verify_v2.py
../.venv/bin/python test_iterations.py --round 5
```

`PLAYWRIGHT_MODULE` 与 `CHROME_EXECUTABLE` 可指定已有环境。脚本自动分配临时数据库、账号和端口，缺依赖时报告问题，不自动安装；完整 HTTP 检查含 macOS OCR 与字体，目前不宣称跨系统全部通过。`qa_browser.cjs` 是首版历史检查，当前使用上述脚本。不要并行启动两份完整组合检查，也不要在运行中修改被测源码。

`iteration_cycle.py` 是严格顺序检查点与收据工具，不定时调度任务。公开副本不含原 `verification/iterations/` 完成目录，fresh clone 的 `status` 为 `ready`；复验或启动新的开发周期与原环境历史五轮分开，复验不会自动创建历史 completion。详细模块、接口与数据一致性约束见[API 契约](API契约.md)和[开发计划](../产品开发计划.md)。
