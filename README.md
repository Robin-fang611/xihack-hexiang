面向 XiHack 2026 企业命题三和香方向的本地软件原型：用有来源的文化知识与复合调香规则，让用户自由探索、分析已有香品、创作个人香笺；管理者可选择把自己的实体商品挂到首页并提供商家购买链接。

## 本机运行

需要 Python 3.11 或更高版本。以下命令面向 macOS/Linux 的本地环境，完整功能已在 macOS 验证；安装由拉取仓库的人在自己的环境执行，公开过程不替协作者安装依赖。

```sh
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app/server.py --port 8870
```

在启动服务的这台电脑打开 [127.0.0.1:8870](http://127.0.0.1:8870)。这个地址只指向访问者自己的电脑，不是公共网站。macOS 也可双击 `app/启动软件.command`，它优先使用仓库的虚拟环境。Windows 的时区数据与 OCR 环境尚未适配和验证。

首次初始化自动生成本机管理者账号，存放于 `app/.local/本机管理者账号.txt`；普通用户从界面注册。每位协作者获得自己的新账号与空数据库，仓库没有默认密码或私人资料。服务默认仅监听本机。

照片文字识别使用 macOS Apple Vision，需可用的 Apple Swift 工具链。非 macOS 或工具链不可用时照片可保存并手动补充文字；文本、可提取文字的 PDF 和 Word 资料分析仍可使用。扫描 PDF 可改传照片，PDF 取前 5 页，单份附件上限 8MB。静态页面不依赖外部字体、脚本或 CDN。

## 五轮带来了什么

手机主操作提前到约 1320px，材料可以快捷入案，候选差异有依据；用户原话通过本机词表形成待确认的条件提案，冲突与未知保持清楚。草稿在本标签页刷新接续，保存和 PNG 下载独立，旧作品可明确回案头继续。软件模拟在服务端确认后真实计时，到时后台停止；商品并发修改返回 409 并保留编辑。现代图鉴可筛选选材，传统材料和历史原名不会直接混入现代参照；共享 Cookie 换号与注销竞态受到保护。

详见[软件使用说明](app/README.md)。当前分析与设计使用本机知识规则，没有调用外部大模型或付费接口；数字设计与软件模拟不证明实际气味、制造兼容或健康功效。

## 复核

基础检查在仓库根目录运行：

```sh
.venv/bin/python 知识库/核验知识库.py --self-test
.venv/bin/python 知识库/验证数字调香.py
.venv/bin/python app/test_app.py
```

当前完整回归与五轮组合检查需在 `app/` 目录运行，并使用已有 Node、Playwright 与 Chrome：

```sh
cd app
../.venv/bin/python verify_v2.py
../.venv/bin/python test_iterations.py --round 5
```

可以通过 `PLAYWRIGHT_MODULE`、`CHROME_EXECUTABLE` 指定已有 Playwright 模块与 Chrome 可执行路径。脚本自动创建临时资料与端口，不操作正式 `app/.local/`；缺少运行库时报告问题，不自动安装。完整 HTTP 检查含 Apple Vision OCR 与 macOS 字体，目前不宣称跨系统全部测试通过。`qa_browser.cjs` 保留为首版历史工具，当前复核使用上述脚本。

原开发五轮已正式完成，最终在 38 份运行源码指纹下有 36 项组合行为检查、57 项模块检查通过，另有 9 组 HTTP、29 项调香、8 类知识边界、12 组浏览器流程（48 项布局）。36 项来自同一源码下 32 项基础验收与 4 项补验，过程失败与纠正保留，未声称一次无失败执行。

本次公开副本还完成了一次独立完整复验：36 项组合行为、57 项模块检查及原有完整回归全部通过；38 份运行源码与原最终版逐字节一致。公开环境的一分钟计时在独立 Chrome 关闭约 63.47 秒后已后台自动停止，先核内部状态再请求 HTTP；可配置的验证工具指纹与结果见公开摘要的 public_copy_validation。
